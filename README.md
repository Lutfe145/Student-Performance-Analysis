# Student Performance Analysis

## Overview
This project analyzes student performance data using Python and Pandas.

## Objectives
- Load and clean the dataset
- Analyze student grades
- Compare gender performance
- Study relationship between study time and grades
- Create visualizations

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Analysis Performed
1. Average Final Grade (G3)
2. Students scoring above 15
3. Study Time vs Performance
4. Gender-wise Performance Comparison

## Visualizations
- Histogram of Final Grades
- Scatter Plot of Study Time vs Grades
- Bar Chart of Average Grade by Gender

## Dataset
Student Performance Dataset (UCI Machine Learning Repository)
